# Спека кампании PVC-компаунда (порядок групп, хеш, премикс)

Статус: **решение принято 04.08.2026, уточнено 05.08.2026** (внешняя
архитектурная сессия: геометрия UV, всё-или-ничего, состав групп).
Цели кампании: глянец 8–10 GU, белесость при резе, цена.

## 1. Порядок функциональных групп — ЗАФИКСИРОВАН

```
FILLER → SOFT → ACR → LUB → STAB
```

### Почему порядок — часть спеки

Групповой сэмплер (iter31, `SimplexRegion.random_points(groups=…)` /
`MixtureProcessRunner.set_mixture_sampling_groups`) работает
последовательным сужением: **точную равномерную маргиналь по сумме
получает только ПЕРВАЯ перечисленная группа** (замер iter34:
KS≈0.019), последующие — условную (KS≈0.38, coverage≈0.80, края
достижимы). Три равномерные маргинали при Σx=1 несовместимы
математически — это документированное свойство меры, а не баг
(см. `tests/unit/test_iteration34_findings_recheck.py`).

Следствие: **порядок групп = приоритет осей кампании.**

### Обоснование выбранного порядка

| # | Группа | Приоритет |
|---|--------|-----------|
| 1 | `FILLER` (мел) | Главный рычаг цены И главный антагонист белесости — ему нужна безупречная (точная) маргиналь. |
| 2 | `SOFT` | Пластификация/мягкость — второй по влиянию рычаг свойств. |
| 3 | `ACR` (акриловые процессинговые) | Влияние на глянец/переработку; условное покрытие 0.80 приемлемо. |
| 4 | `LUB` (лубриканты) | Тюнинг переработки. |
| 5 | `STAB` (стабилизаторы) | Узкий диапазон; эффект дополнительно проверяется купонным под-планом. |

Coverage ≈0.80 у поздних групп — приемлемо: это тюнинг, а не блокер.

### Состав групп — ПОДТВЕРЖДЁН (внешняя сессия 05.08.2026)

| Группа | Компоненты |
|--------|------------|
| FILLER | Chalk_1T, Chalk_95T |
| SOFT   | CPE_135A, PBNK_3355 |
| ACR    | PMPlus_8, DL_531 |

| (fixed, вне групп) | SA_1860, ESO — **фиксированные phr; значения ввести при сетапе** (в референсной 17-компонентной спеке тестов пока отсутствуют; добавление узлов `fixed` изменит хеш спеки — см. §2) |

## 2. Геометрия UV_CSFCP: ТРАПЕЦИЯ, а не клин (правка 05.08.2026)

Растворимость ограничивает УФ-абсорбер **только сверху**; нижняя
граница 0.05 phr — требование по защите, от пластификатора не зависит:

```
p_UV ∈ [0.05, min(0.30, 0.03 · p_DINP)]      # трапеция
```

Прежний `ratio_to` (клин `p_UV ∈ [θ_L·p_DINP, θ_U·p_DINP]`) был неверен:
(1) не давал низкий УФ при высоком ДИНФ; (2) вшивал corr(p_UV, p_DINP)≈0.9
с самой сильной осью рецептуры; (3) навязывал монотонный prior
«больше пластификатора → больше абсорбера», которого физика не требует.

Реализация: `PhrSpec` режим `absolute` + `cap_to`/`cap_ratio`
(`src/design/phr_sampler.py`). Golden-числа потолка
(`tests/unit/test_iteration35_phr_spec_campaign.py::TestUvTrapezoidGeometry`):

| DINP, phr | hi_eff = min(0.30, 0.03·DINP) |
|-----------|-------------------------------|
| 4         | **0.12** |
| 10        | **0.30** (начало полки) |
| 14        | **0.30** (полка) |

Замеры на плане-кандидатах (n=4096): corr(p_UV, p_DINP) = **0.42**
(было ≈0.9 у клина). Честная оговорка: порог «< 0.4» из внешней сессии
недостижим при равномерной маргинали DINP — 0.4235 аналитически есть
геометрический пол ФОРМЫ трапеции; опустить ниже можно, лишь исказив
маргиналь доминирующей оси DINP (осознанно не делаем). Порог теста 0.45.
Свобода УФ при малом титане: при TiO2 < 1 phr max/min по UV > 3 — тест.

## 4. Однородность меры плана: всё-или-ничего (правка 05.08.2026)

`SimplexRegion.random_points` (iter36): если rejection-путь не набирает
план (узкие границы), частичные точки **отбрасываются** и ВЕСЬ план
перегенерируется narrowing'ом. Раньше остаток «добирался» — план
становился смесью двух распределений, причём narrowing-точки
концентрировались в труднодостижимых углах (где информация дороже
всего). `last_sampling_info["method"]` теперь всегда однороден:
`"rejection" | "narrowing" | "grouped"` — preflight/аудит могут на это
опираться (тест `test_method_is_always_homogeneous`, iter34-файл).

Рецептурная кампания это правило не задевает: phr-путь (`PhrSpec`)
работает вовсе без rejection.

## 5. Правило премикса (слой навески)

`src/design/phr_sampler.premix_required(delta_phr, lo, hi, threshold=0.05)`:

    delta_phr / (hi − lo) > 0.05  ⇒  дозировать через премикс

где `delta_phr` — шаг весов, переведённый в phr загрузки. Пример
(весы 0.1 г, 5 г на 1 phr → δ = 0.02 phr):

| Компонент | Диапазон phr | δ/(U−L) | Вывод |
|-----------|--------------|---------|-------|
| SBM_55    | 0.07–0.45    | 0.053   | премикс |
| UV_CSFCP  | 0.05–0.30    | 0.080   | премикс |
| DINP      | 4–14         | 0.002   | прямая навеска |
