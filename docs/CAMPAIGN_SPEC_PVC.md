# Спека кампании PVC-компаунда (порядок групп, хеш, премикс)

Статус: **решение принято 04.08.2026, уточнено 05.08.2026** (внешние
архитектурные сессии: геометрия UV — потолок по пластификаторной ФАЗЕ,
fixed-значения ESO/SA_1860, всё-или-ничего, состав групп).
Цели кампании: глянец 8–10 GU, белесость при резе, цена.

## 1. Порядок функциональных групп — ЗАФИКСИРОВАН

```
FILLER → SOFT → ACR → LUB → STAB
```

### Почему порядок — часть спеки

Групповой сэмплер (iter31, `SimplexRegion.random_points(groups=…)` /
`MixtureProcessRunner.set_mixture_sampling_groups`) работает
последовательным сужением: **точную равномерную маргиналь по сумме
получает только ПЕРВАЯ перечисленная группа** (замер iter34:
KS≈0.019), последующие — условную (KS≈0.38, coverage≈0.80, края
достижимы). Три равномерные маргинали при Σx=1 несовместимы
математически — это документированное свойство меры, а не баг
(см. `tests/unit/test_iteration34_findings_recheck.py`).

Следствие: **порядок групп = приоритет осей кампании.**

### Обоснование выбранного порядка

| # | Группа | Приоритет |
|---|--------|-----------|
| 1 | `FILLER` (мел) | Главный рычаг цены И главный антагонист белесости — ему нужна безупречная (точная) маргиналь. |
| 2 | `SOFT` | Пластификация/мягкость — второй по влиянию рычаг свойств. |
| 3 | `ACR` (акриловые процессинговые) | Влияние на глянец/переработку; условное покрытие 0.80 приемлемо. |
| 4 | `LUB` (лубриканты) | Тюнинг переработки. |
| 5 | `STAB` (стабилизаторы) | Узкий диапазон; эффект дополнительно проверяется купонным под-планом. |

Coverage ≈0.80 у поздних групп — приемлемо: это тюнинг, а не блокер.

### Состав групп — ПОДТВЕРЖДЁН (внешняя сессия 05.08.2026)

| Группа | Компоненты |
|--------|------------|
| FILLER | Chalk_1T, Chalk_95T |
| SOFT   | CPE_135A, PBNK_3355 |
| ACR    | PMPlus_8, DL_531 |
| LUB    | DL_60, AKLUB_K_435, OPE |
| STAB   | PF711, PF711LB |
| (вне групп) | PVC_67, PVC_71 (смола, share-группа = 100 phr), DINP, TiO2_BLR895, SBM_55, UV_CSFCP |
| (fixed, вне групп) | SA_1860 = **0.10 phr**, ESO = **2.50 phr** (значения зафиксированы 05.08.2026, входят в референсную 19-компонентную спеку тестов iter35) |

### Fixed-значения сетапа — ЗАФИКСИРОВАНЫ (внешняя сессия 05.08.2026)

| Компонент | phr | Обоснование |
|---|---|---|
| **ESO** | **2.50** | Штатный синергист триады Ca/Zn + β-дикетон; без него SBM_55 работает заметно слабее. ⚠️ Перед сетапом проверить, нет ли ЭСО уже внутри PF711 — при двойном учёте база для θ_SBM поедет |
| **SA_1860** | **0.10** | Технологический минимум как антиадгезив. Не выше: снижает SME → ухудшает сплавление и белесость при резе; plate-out заполняет микрорельеф матового вала. Роль внутренней смазки полностью закрыта DL_60 |

Следствия фиксации (пересчитаны перед фиксацией хеша):

* эффективная пластификация теперь **6.5–16.5 phr** (не 4–14) — меняет
  ожидания по твёрдости и по вязкостному отношению p = η_d/η_m;
* T_min/T_max суммарного phr сдвинуты на **+2.6** (констант, где это
  зашито, в коде нет — fraction_bounds считается от спеки динамически).

## 2. Геометрия UV_CSFCP: ТРАПЕЦИЯ по пластификаторной ФАЗЕ (правки 05.08.2026)

Растворимость ограничивает УФ-абсорбер **только сверху**; нижняя
граница 0.05 phr — требование по защите, от пластификатора не зависит.
Референс потолка — **пластификаторная фаза целиком**, а не один ДИНФ:
UV-P растворяется в пластификаторе как фазе, ЭСО — эпоксидированный
эфир, полноценный вторичный пластификатор и такой же растворитель для
UV-P. При fixed ESO = 2.5 phr:

```
p_UV ∈ [0.05, min(0.30, 0.03 · (p_DINP + p_ESO))]      # трапеция по фазе
```

Прежний `ratio_to` (клин `p_UV ∈ [θ_L·p_DINP, θ_U·p_DINP]`) был неверен:
(1) не давал низкий УФ при высоком ДИНФ; (2) вшивал corr(p_UV, p_DINP)≈0.9
с самой сильной осью рецептуры; (3) навязывал монотонный prior
«больше пластификатора → больше абсорбера», которого физика не требует.

Реализация: `PhrSpec` режим `absolute` + `cap_to`/`cap_ratio`
(`src/design/phr_sampler.py`); `cap_to` — имя узла или СПИСОК имён
(значения складываются: `cap_to: [DINP, ESO]`), так что при переводе ЭСО
в переменные или добавлении ECOD-FLEX на кромочной ветке переписывать
семантику не придётся. Golden-числа потолка
(`tests/unit/test_iteration35_phr_spec_campaign.py::TestUvTrapezoidGeometry`):

| DINP, phr | hi_eff = min(0.30, 0.03·(DINP+2.5)) |
|-----------|-------------------------------------|
| 4         | **0.195** |
| 7.5       | **0.30** (излом: DINP+ESO = 10, начало полки) |
| 14        | **0.30** (полка) |

Излом сдвинулся с D=10 на D=7.5, наклонный участок сжался с 60% до 35%
диапазона. corr(p_UV, p_DINP): аналитически Cov=0.0353, σ_UV=0.0692 ⇒
ρ≈0.18; замер 05.08.2026: **0.166** (n=4096), 0.176 (n=200000).
Порог теста **0.25** — при корректном cap он проходится с запасом, тест
снова осмысленный сторож, а не документация геометрии.

История спора о пороге (закрыт исправлением модели, не компромиссом):
при cap_to=DINP (неверный референс) геометрический пол ФОРМЫ трапеции
был 0.4235 аналитически (замер 0.42), опустить ниже можно было лишь
исказив маргиналь доминирующей оси DINP; при этом даже 0.42 для GP был
безвреден по собственному гейту коллинеарности (VIF = 1/(1−0.179) =
1.22 ≪ 5). Правка референса на фазу опускает corr ниже любого
обсуждавшегося порога БЕЗ искажения маргинали. Побочно открылся угол
«мало пластификатора + средний УФ»: при DINP=4 потолок 0.12 → 0.195.

Граница фазы: **DINP + ESO**. DL_60 (эфирная внутренняя смазка,
0.12–0.84 phr) в фазу НЕ включаем: вклад в растворимость UV-P не
документирован, эффект на потолок ≲ 0.025 phr — внутри погрешности
самой оценки растворимости (≈2–3%, по аналогии с бутилацетатом).
Значение 0.03 консервативно; при первых признаках bloom уточнять
экспериментально, а не арифметикой.

Свобода УФ при малом титане: при TiO2 < 1 phr max/min по UV > 3 — тест.

## 4. Однородность меры плана: всё-или-ничего (правка 05.08.2026)

`SimplexRegion.random_points` (iter36): если rejection-путь не набирает
план (узкие границы), частичные точки **отбрасываются** и ВЕСЬ план
перегенерируется narrowing'ом. Раньше остаток «добирался» — план
становился смесью двух распределений, причём narrowing-точки
концентрировались в труднодостижимых углах (где информация дороже
всего). `last_sampling_info["method"]` теперь всегда однороден:
`"rejection" | "narrowing" | "grouped"` — preflight/аудит могут на это
опираться (тест `test_method_is_always_homogeneous`, iter34-файл).

Рецептурная кампания это правило не задевает: phr-путь (`PhrSpec`)
работает вовсе без rejection.

## 5. Правило премикса (слой навески)

`src/design/phr_sampler.premix_required(delta_phr, lo, hi, threshold=0.05)`:

    delta_phr / (hi − lo) > 0.05  ⇒  дозировать через премикс

где `delta_phr` — шаг весов, переведённый в phr загрузки. Пример
(весы 0.1 г, 5 г на 1 phr → δ = 0.02 phr):

| Компонент | Диапазон phr | δ/(U−L) | Вывод |
|-----------|--------------|---------|-------|
| SBM_55    | 0.07–0.45    | 0.053   | премикс |
| UV_CSFCP  | 0.05–0.30    | 0.080   | премикс |
| DINP      | 4–14         | 0.002   | прямая навеска |

**Квантование nominal → actual (iter37, скрин-аудит п.3):**
`PhrSpec.quantize_recipe(p, delta_phr)` — каждый лист снапится к
ближайшему узлу δ-сетки ВНУТРИ своих границ; затем по фактическим
значениям проверяются fixed-значения, границы share/ratio и cap-потолки
(«после округления до разрешения весов точка всё ещё в границах»).
Нарушения — явные `violations` (`ok=False`): интервал уже шага весов,
fixed вне сетки, вылет за трапецию UV. **Дозировать и хранить надо
ФАКТИЧЕСКИЕ значения (`p_actual`), модель должна видеть actual, а не
nominal.**

## 5a. Гейты и метаданные кампании (iter37, скрин-аудит 05.08.2026)

Пять пунктов внешнего аудита «что реально не закрыто» реализованы
(`tests/unit/test_iteration37_campaign_gaps.py`):

1. **Staged-аугментация.** `propose_seed` при непустой базе (например,
   после `augment_phase_mixture` — ПБНК/ECOD-FLEX-сценарии) пристёгивает
   план к существующим точкам жадным maximin (`propose_augment`), а не
   генерирует с нуля: фаза 2 заполняет дыры относительно фазы 1.
2. **Метаданные точки.** Перед сетапом задать `set_campaign_label(...)`;
   каждая точка получает в `origin_tag`: `campaign`, `spec_hash`
   (отпечаток активной phr-спеки), `schema_version` (фаза), `block`
   (партия) — постфактум эти метаданные не восстанавливаются.
3. **Квантование** — см. §5 (`quantize_recipe`).
4. **Обязательные 2D-пары.** Перед сетапом задать
   `set_preflight_pairs([...])` — preflight проверит покрытие 2D-сетки
   каждой пары относительно reference-пула. Для этой кампании:
   `(UV_CSFCP, TiO2_BLR895)`, `(T_пласт, UV_CSFCP)`,
   `(ΔT, ["PMPlus_8", "DL_531"])` (Σ_ACR — ось-сумма),
   `(DINP, TiO2_BLR895)` (маслоёмкость); process-имена — по фактической
   схеме кампании.
5. **PROCESS-оси — Sobol.** Пулы кандидатов сэмплят process-куб
   scrambled-Соболем (не iid uniform): при 4 осях и ожидаемых
   взаимодействиях покрытие пар осей равномерное.

## 7. Постановка откликов кампании (iter39, блокер 2 закрыт)

Desirability-свёртка — НЕ для всех откликов; постановка зафиксирована
до сетапа (`src/optimize/desirability.py`,
`tests/unit/test_iteration39_sigma_channel.py`):

| Отклик | Постановка | Инструмент |
|---|---|---|
| **Желатинизация** | двусторонний ТАРГЕТ **60–70 %** (НЕ larger-is-better: пере-желатинизация разрушает сеть CPE, белесость растёт) | `DesirabilitySpec("target", low=60, high=70+δ, target=65)` — калибровать low/high/target по факту при сетапе |
| **Adhesion** | жёсткий порог на предсказанное СРЕДНЕЕ, ramp = шум измерения отклика (не «узкий»: нулевой ramp — плоский нуль без направления возврата) | `hard_threshold_spec(threshold, noise_sd, "ge")` |
| **Opacity** | то же; при TiO2 < 1 phr ожидаем биндинг — смотреть `binding_report` | `hard_threshold_spec(...)` + `DesirabilityResult.binding_report` |
| **ΔE (УФ)** | вероятностное: `Pr(ΔE ≤ ΔE_max) ≥ 1−α` ОТДЕЛЬНО по колористическим группам (потери асимметричны: недодоз = рекламации в поле) | `ChanceConstraint(y_max=ΔE_max, alpha=α)` через `optimize_xbest(chance_constraints=…)` — σ берётся из общих суррогатов автоматически |

`binding_report` каждой оптимизации — обязателен к просмотру: он
отличает «оптимум не найден» от «оптимум запрещён» (сколько точек пула
под veto/ниже 1−α и активность ограничений в x*). Ответ на вопрос
«забиндилась ли Opacity при TiO2 < 1» придёт именно отсюда.
